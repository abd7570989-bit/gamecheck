# GameCheck

برنامج مجاني بالكامل لنظام Windows يفحص مواصفات جهازك ويقارنها بمتطلبات الألعاب، ثم يخبرك هل ستعمل اللعبة بالإعدادات الموصى بها أو بالحد الأدنى، أو أنها لن تعمل.

- **مجاني مدى الحياة:** كل الميزات متاحة للجميع. لا توجد نسخة مدفوعة ولا اشتراكات ولا صفحات شراء.
- **بدون حساب:** لا تسجيل دخول ولا بريد إلكتروني.
- **يعمل دون إنترنت:** فحص الجهاز ومقارنة المتطلبات يتمّان بالكامل على جهازك.
- **بدون إعلانات أو تتبع:** البرنامج لا يرسل أي معلومات عن جهازك أو عنك. الاتصال الوحيد بالإنترنت هو تنزيل مكتبة الألعاب، وذلك فقط عندما تضغط زر «تحديث مكتبة الألعاب».
- **خفيف:** ملف واحد حجمه نحو 8 ميغابايت، لا يحتاج تثبيتًا، ولا يحتاج صلاحيات المسؤول.

## تعليمات التشغيل (للمستخدم)

1. نزّل الملف `GameCheck.exe`.
2. انقر عليه نقرًا مزدوجًا. لا يحتاج البرنامج إلى تثبيت.
3. قد يظهر تحذير Windows SmartScreen («Windows protected your PC») لأن الملف غير موقَّع رقميًا. اضغط **More info** ثم **Run anyway**. انظر قسم «التوقيع الرقمي» أدناه.
4. تُفتح نافذة سوداء صغيرة، ثم تُفتح واجهة البرنامج تلقائيًا في متصفحك الافتراضي.
   - الواجهة تعمل على جهازك فقط (العنوان يبدأ بـ `http://127.0.0.1`) ولا تتصل بأي موقع.
   - إذا لم يُفتح المتصفح، انسخ العنوان الظاهر في النافذة السوداء والصقه في المتصفح.
5. ستظهر مواصفات جهازك وقائمة الألعاب، وبجانب كل لعبة النتيجة. اضغط على اللعبة لرؤية المقارنة التفصيلية لكل قطعة.
6. **لإغلاق البرنامج:** اضغط زر «خروج» في الواجهة، أو أغلق النافذة السوداء.

### معنى النتائج

| النتيجة | المعنى |
|---|---|
| يعمل بالإعدادات الموصى بها | جهازك يحقق أو يتجاوز المتطلبات الموصى بها |
| يعمل بالحد الأدنى | جهازك يحقق الحد الأدنى، فتوقّع إعدادات منخفضة أو متوسطة |
| قد يعمل بإعدادات منخفضة | أداء المعالج أو كرت الشاشة أقل من الحد الأدنى بفارق صغير (حتى 10%) |
| أقل من الحد الأدنى | قطعة واحدة على الأقل أضعف بوضوح من المطلوب |
| غير مؤكد | لم يتعرف البرنامج على قطعة ما، فلا يخمّن. يمكنك اختيارها يدويًا |

إذا كانت **المساحة الحرة** غير كافية، يظهر تنبيه منفصل («تحتاج مساحة حرة إضافية»). هذا التنبيه لا يغيّر النتيجة، لأن المساحة يمكن توفيرها.

### إذا لم يتعرف البرنامج على قطعة

اضغط «اختر المعالج أو كرت الشاشة يدويًا»، ثم ابدأ بكتابة اسم القطعة واخترها من القائمة. يُحفظ اختيارك على جهازك فقط، ويمكنك العودة إلى الاكتشاف التلقائي في أي وقت.

### تحديث مكتبة الألعاب

- عند وجود إنترنت، اضغط «تحديث مكتبة الألعاب». تُنزَّل أحدث قائمة ألعاب، ويتحقق البرنامج من صحتها، ثم تُحفظ على جهازك.
- بعد ذلك تبقى المكتبة المحفوظة متاحة دون إنترنت.
- إذا لم يتوفر إنترنت أو كان الملف المنزَّل تالفًا، يستمر البرنامج بالمكتبة الموجودة ولا يتغير شيء.

### خيارات سطر الأوامر

```bash
GameCheck.exe --report
```

يطبع تقريرًا نصيًا لكل الألعاب دون فتح المتصفح. خيارات أخرى:

| الخيار | العمل |
|---|---|
| `--json` | يطبع النتائج بصيغة JSON |
| `--update-library` | يحدّث مكتبة الألعاب ثم يخرج |
| `--no-browser` | يشغّل الواجهة دون فتح المتصفح تلقائيًا |
| `--port 8765` | يستخدم منفذًا محددًا بدل منفذ عشوائي |

### أين تُحفظ البيانات؟ وكيف أحذف البرنامج؟

يحفظ البرنامج ملفين فقط في `%LOCALAPPDATA%\GameCheck`:

- `library.json`: مكتبة الألعاب المحدَّثة، إن وُجدت.
- `settings.json`: اختياراتك اليدوية، إن وُجدت.

لا يُحفظ أي شيء آخر، ولا يكتب البرنامج في سجل Windows. لحذف البرنامج، احذف `GameCheck.exe` ثم هذا المجلد.

## دقة المقارنة: ما الذي تعتمد عليه وما حدودها

- **المعالج وكرت الشاشة:** يُحوَّل اسم القطعة إلى طراز معروف، ثم يُقارن «مؤشر أداء» تقديري لها بمؤشر القطعة المطلوبة. عندما تذكر اللعبة أكثر من قطعة (مثل «GTX 1060 أو RX 580»)، يكفي أن يعادل جهازك أضعفها.
- **مؤشرات الأداء تقديرية:** جُمعت من متوسطات اختبارات أداء عامة، وتصلح للمقارنة لا لقياس عدد الإطارات. لذلك وُضع هامش «قريب من الحد» بنسبة 10%.
- **كروت اللابتوب:** يُقدَّر أداؤها بنحو 80% من النسخة المكتبية التي تحمل الاسم نفسه، ويظهر تنبيه بذلك.
- **ذاكرة الفيديو:** تُقرأ من تعريف كرت الشاشة. إذا لم تتوفر، تُستخدم السعة المعتادة للطراز. الكروت المدمجة تستخدم ذاكرة مشتركة، لذلك لا تُقارن ذاكرة الفيديو فيها.
- **الذاكرة RAM:** تُقرأ الذاكرة المركّبة فعليًا مع هامش 5%، حتى لا تفشل لعبة تطلب 16 GB على جهاز يُظهر 15.9 GB.
- **ما لا يفحصه البرنامج حاليًا:** نوع القرص (SSD أو HDD) ويظهر كتنبيه فقط، ونسخة DirectX، وتعريفات كرت الشاشة.
- **القطع غير المعروفة:** إن لم يتعرف البرنامج على قطعة، يقول ذلك صراحةً بدل أن يخمّن.
- **بيانات الألعاب:** جُمعت متطلبات الألعاب الأربع عشرة الحالية من صفحاتها الرسمية بحسب ما هو معروف لنا. قد تغيّر الشركات متطلباتها بعد التحديثات، لذلك يحمل كل إدخال رابط المصدر لمراجعته. راجع [docs/UPDATING_LIBRARY.md](docs/UPDATING_LIBRARY.md).

## للمطوّر: البناء والاختبار

الكود بلغة Python ويستخدم المكتبة القياسية فقط، أي دون أي اعتماديات وقت التشغيل.

| المسار | المحتوى |
|---|---|
| `gamecheck/scanner.py` | قراءة مواصفات الجهاز محليًا (سجل Windows و`kernel32`، دون PowerShell ودون إنترنت) |
| `gamecheck/hardware_db.py` | التعرف على أسماء المعالجات وكروت الشاشة |
| `gamecheck/compare.py` | منطق المقارنة والنتائج |
| `gamecheck/library.py` | تحميل مكتبة الألعاب وتحديثها والتحقق منها |
| `gamecheck/server.py` | الواجهة المحلية، وتستمع على `127.0.0.1` فقط مع رمز حماية لكل تشغيل |
| `gamecheck/web/index.html` | الواجهة العربية، دون أي ملفات خارجية |
| `gamecheck/data/library.json` | المكتبة المضمَّنة، وتُولَّد من `tools/build_library.py` |

### بناء ملف EXE

**الطريقة الأولى: على جهاز Windows.** ثبّت Python 3.12 من python.org (فعّل «Add to PATH»)، ثم شغّل:

```bash
build_windows.bat
```

النتيجة: `dist\GameCheck.exe`. يشغّل السكربت الاختبارات قبل البناء.

**الطريقة الثانية: GitHub Actions.** ارفع المشروع إلى مستودع على GitHub، وسيبني الملف `.github/workflows/build-windows.yml` الـ EXE على جهاز Windows حقيقي. يختبره كذلك (الاختبارات، وتقرير الفحص، واختبار الواجهة في المتصفح)، ثم يرفعه كملف قابل للتنزيل. عند إنشاء وسم مثل `v1.0.0`، يُنشر الملف تلقائيًا في صفحة Releases. هذا مجاني للمستودعات العامة.

### تشغيل الاختبارات

```bash
python -m pytest -q
```

```bash
node tests/ui/ui_test.js
```

الأمر الأول يشغّل اختبارات الوحدات. الثاني يختبر الواجهة في المتصفح ويحتاج Playwright. يمكن تمرير مسار الـ EXE إليه لاختبار النسخة المبنية:

```bash
node tests/ui/ui_test.js dist/GameCheck.exe
```

### التوقيع الرقمي (اختياري، ولم يُضَف)

الملف غير موقَّع، لذلك يظهر تحذير SmartScreen في أول تشغيل. قد تصنّف بعض برامج الحماية ملفات PyInstaller خطأً كملفات مشبوهة. الحل الدائم هو شهادة توقيع كود، وهي خدمة مدفوعة سنويًا ولم نضفها. القرار لك، ويمكن إضافتها لاحقًا دون تغيير الكود. حتى ذلك الحين، يُنشر مع كل إصدار ملف `GameCheck.exe.sha256` ليتحقق المستخدم من سلامة الملف.
