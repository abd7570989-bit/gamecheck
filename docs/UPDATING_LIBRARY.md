# تحديث مكتبة الألعاب

مكتبة الألعاب ملف JSON واحد يحتوي على:

- مؤشرات أداء المعالجات (`cpus`).
- مؤشرات أداء كروت الشاشة (`gpus`).
- متطلبات الألعاب (`games`).

نسخة منها مضمَّنة داخل الـ EXE، ويمكن للمستخدمين تنزيل نسخة أحدث من الإنترنت.

## 1) استضافة المكتبة مجانًا

لا تحتاج خادمًا ولا خدمة مدفوعة. يكفي ملف ثابت في مستودع GitHub عام:

1. ارفع المشروع إلى مستودع GitHub عام.
2. رابط الملف الخام سيكون بهذا الشكل:

   ```
   https://raw.githubusercontent.com/<اسم-الحساب>/<اسم-المستودع>/main/gamecheck/data/library.json
   ```

3. ضع هذا الرابط في `DEFAULT_LIBRARY_URL` داخل `gamecheck/library.py`، ثم ابنِ الـ EXE.

حاليًا الرابط فارغ عمدًا لأنه لا يوجد مستودع بعد. لذلك يُظهر زر التحديث رسالة «لم يُضبط مصدر لتحديث المكتبة»، ويستمر البرنامج في العمل بالمكتبة المضمَّنة.

**الخصوصية:** طلب التحديث طلب `GET` عادي، دون أي معرّف أو ملفات تعريف ارتباط (cookies) أو معلومات عن الجهاز. GitHub كأي خادم يرى عنوان IP الخاص بمن يطلب الملف، والبرنامج لا يرسل شيئًا غير ذلك.

## 2) إضافة لعبة أو تعديلها

1. عدّل الجداول في `tools/build_library.py`: أضف اللعبة إلى `GAMES`، وأضف أي معالج أو كرت شاشة جديد إلى `CPUS` أو `GPUS`.
2. **زِد `LIBRARY_VERSION` بمقدار 1.** النسخ المثبتة لا تنزّل إلا مكتبة رقمها أكبر من رقم مكتبتها.
3. أعد توليد الملف:

   ```bash
   python tools/build_library.py
   ```

4. شغّل الاختبارات:

   ```bash
   python -m pytest -q
   ```

   الاختبارات تفشل إذا ذكرت لعبةٌ قطعةً غير موجودة في الجداول، أو إذا كانت المتطلبات الموصى بها أقل من الحد الأدنى. هذا يمنع نشر مقارنة خاطئة.
5. ارفع التعديل إلى المستودع. سيحصل المستخدمون على المكتبة الجديدة عند ضغط زر التحديث.

### صيغة اللعبة

```python
{
    "id": "elden-ring",                    # معرّف فريد بأحرف إنجليزية
    "name": "Elden Ring",
    "source": "https://store.steampowered.com/app/1245620/",   # مصدر المتطلبات
    "minimum": tier(["Intel Core i5-8400", "AMD Ryzen 3 3300X"],          # أي واحد منها يكفي
                    ["NVIDIA GeForce GTX 1060 3GB", "AMD Radeon RX 580"],
                    12, 60, vram=3),       # RAM بالـ GB، المساحة بالـ GB، ذاكرة الفيديو
    "recommended": tier([...], [...], 16, 60, vram=8),   # اختياري
}
```

اكتب أسماء القطع كما هي في الجداول. إذا كتبتها بصيغة مختلفة قليلًا، سيتعرف عليها البرنامج غالبًا، والاختبارات تتحقق من ذلك.

### مؤشرات الأداء

- المعالجات: Core i5-4460 = 100.
- كروت الشاشة: GTX 1060 6GB = 100.

القيم تقديرية من متوسطات اختبارات الأداء العامة. عند إضافة قطعة جديدة، قارنها بقطع معروفة قريبة منها في الأداء.

## 3) مراجعة البيانات قبل النشر

جُمعت متطلبات الألعاب الحالية من صفحاتها الرسمية بحسب المعرفة المتاحة وقت الكتابة، ولم تُراجَع آليًا مقابل المتاجر. قبل النشر العام، افتح رابط `source` لكل لعبة وطابق الأرقام، خصوصًا المساحة المطلوبة، لأنها تتغير كثيرًا مع التحديثات.
